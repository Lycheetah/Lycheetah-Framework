# App UI Copy Contract
## Truth Pressure App RC v0.5

## Main label

**Revision pressure index**

Never display:

```text
Truth probability
Truth percentage
Accuracy
Verified truth
```

## Mandatory boundary

> This is a review signal under declared inputs. It is not a probability that the claim is true.

## Component labels

```text
E — Evidence
Inspectable support available under the current assessment.

P — Explanatory reach
How much mechanism, prediction, scope, or unification has been earned.

S — Unresolved strain
Contradiction, ambiguity, missing evidence, or alternatives still unresolved.
```

## Text mode

**Provisional text triage**

> This reading is pattern-based and may miss meaning. Build a structured assessment before using it for knowledge review.

## No threshold

> No validated review threshold is configured. The score is descriptive only.

## Threshold exceeded

> The configured review threshold was exceeded. This opens review. It does not authorize automatic replacement.

## Approval

Button:

```text
Review proposed movement
```

Confirmation:

> Move the selected material outward while preserving the original state for reversal?

Do not use:

```text
Accept truth
Delete false belief
Auto-correct knowledge
```

## Judge failure

> The assessment response was incomplete or invalid. Existing scores were preserved.

## Source status

```text
UNVERIFIED — named but not checked
INSPECTABLE — a source record can be opened
VERIFIED — checked under the declared verification process
```

## Color rule

Colors may represent:

```text
component level
warning state
review state
provenance status
```

Colors must not imply:

```text
green = true
red = false
high pressure = correct
low pressure = incorrect
```
