# Collection Checklist

- [ ] Three raters selected independently.
- [ ] Each rater received only their packet and instructions.
- [ ] No engine outputs or expected labels were shared.
- [ ] Raters completed every score, confidence, reason, and ambiguity field.
- [ ] Files were copied into a locked results directory.
- [ ] SHA-256 hashes were recorded before opening responses.
- [ ] Analysis script was run without changing the preregistered formulas.
- [ ] Major disagreements were classified before any calibration.
- [ ] Original completed packets were preserved unchanged.
