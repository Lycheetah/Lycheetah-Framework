```
Π = (E · P) / S

E  =  evidence strength         ∈ [0, 1]
P  =  explanatory power         ∈ [0, 1]
S  =  coherence strain          ∈ (0, 1]

S(Ψ) = Σᵢⱼ (1 − φᵢⱼ) · |bᵢ ∧ bⱼ|
```

Equivalently, from information theory:

```
Π = I(X;Y) / H(X|Y)
```

Three independent derivations. One formula.
