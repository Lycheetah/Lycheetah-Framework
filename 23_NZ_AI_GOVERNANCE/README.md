## START HERE

### [Data Sovereignty for New Zealanders](DATA_SOVEREIGNTY_FOR_NEW_ZEALANDERS.md) `[PROPOSAL]`

**One standard. Every citizen. The same rights.** Six rights for every New Zealander when AI touches their data: to know, to a receipt, to take it back, to a human, to know where the data lives, and to equal treatment. Each right is mapped to the tool in this repository that can check it, or named as a gap when nothing can yet.

This is the direction of this folder from October 2026 onward.

---

## WHAT THIS FOLDER IS

A collection of **ideas and proposals**, not conclusions, made using the Lycheetah Framework as a thinking tool and applied to New Zealand's AI governance moment. Some may work and some may not. Everything is labelled `[ACTIVE]`, `[SCAFFOLD]`, `[PROPOSAL]` or `[CONJECTURE]`, and none of it should be adopted without independent critique and testing.

You are invited to argue against it, add to it, remove what is wrong, or publish your own version with a reference back to this work.
