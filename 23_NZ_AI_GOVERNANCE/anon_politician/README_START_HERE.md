## What is—and is not—proven
Passing unit tests and structural benchmarks establish only the behaviours those tests exercise. They do not establish policy efficacy, predictive accuracy, political neutrality, representative public opinion or an advantage over ordinary policy analysis. The real comparative evaluation remains to be run using a frozen source packet and independent blind reviewers.

## Privacy

## Version policy
The v1.3 handoff is the canonical compiled project package as of this archive. Superseded full handoff ZIPs (v1.0–v1.2) are intentionally not nested again, to avoid large redundant archives. Their substantive project materials are retained in the latest core or in `QUICK_ACCESS/`; the v0.2 source audit workbook is preserved as historical evidence.
