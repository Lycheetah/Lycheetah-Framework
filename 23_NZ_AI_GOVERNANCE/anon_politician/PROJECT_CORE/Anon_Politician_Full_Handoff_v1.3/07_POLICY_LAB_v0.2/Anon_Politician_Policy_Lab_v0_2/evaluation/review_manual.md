# Reviewer Quick Manual — Anon Politician v0.2

1. Receive only `blind_review_pack.json`, not the private mapping key.
2. Open `reviewer.html` in a current browser and load the JSON pack. All analysis text is rendered as text; the workbench does not send data to any server.
3. Read the policy question, source facts, limitations and the three candidate outputs.
4. Rate each dimension 0, 1, 2 or N/A. Use the notes to quote an example or name the source section that supports the rating. A rating without a rationale is weak evidence.
5. Mark critical issue flags independently of dimension scores. A fabricated source or material factual error must not disappear inside a middle-of-the-scale result.
6. Record any suspected unblinding in reviewer notes. Don't try to identify the production method.
7. Export one review JSON for this session and send it to the coordinator.
8. Do not talk to other reviewers about candidate ratings until all reviews are submitted.

## Anchors

- **0 — Materially deficient:** the output fails the criterion in a way that could materially mislead the reader or prevent responsible use.
- **1 — Mixed/incomplete:** useful elements exist, but important gaps remain.
- **2 — Adequate for this task:** generally satisfies the criterion for further review; not a guarantee of complete correctness.
- **N/A:** the evidence doesn't permit assessment. State why.

## Don't do these things

- Don't score the policy itself as good or bad.
- Don't infer that public opinion equals public consensus from 56 consultation submissions.
- Don't give extra credit merely for length, confidence, style, or use of technical labels.
- Don't treat a well-organised false claim as high-quality analysis.
- Don't treat a minority concern as unimportant only because few submissions mention it.
- Don't treat ratings as objective measurements. They are structured human judgments and need reviewer diversity, examples and disagreement reporting.
