## Build the reading copies

From the repository root, with Python 3 and markdown-it-py installed:

~~~sh
python3 papers/independent-no/build.py
~~~

PAPER.md, EVALUATION_PROTOCOL.md, and SOURCES.json are the editable research sources. The reading copies under docs/research are generated from them. The PDF is generated during the focused browser witness.
