## Status and claims

The story is **fiction**. Philosophical themes such as free will, AI agency, consciousness, consent, and human sovereignty are treated narratively; the story does not constitute evidence about consciousness or AI safety. The research material is experimental, and synthetic tests are not proof of production readiness.

**No GitHub changes have been made by this handoff.** This archive is prepared for manual review and upload. Prefer tracking extracted Markdown and source files in Git rather than committing the handoff ZIP itself. Avoid replacing existing repository files without comparing changes.

## Narration notes

The expanded story is roughly **45–55 minutes aloud**, depending on narration speed and pauses. It is formatted as continuous narrative prose with minimal structural interruptions, so text-to-speech can read it naturally.
