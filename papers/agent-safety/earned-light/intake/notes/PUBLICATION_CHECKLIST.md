# Publication Checklist

- [ ] Confirm final storytelling repository and directory.
- [ ] Read the expanded narrative aloud or use text-to-speech once to catch pacing issues.
- [ ] Preserve original short edition if maintaining creative history.
- [ ] Keep research in a separate technical directory/repository.
- [ ] Compare snapshot against upstream and do not overwrite newer commits.
- [ ] Check subproject licence terms.
- [ ] Re-run the research tests in the target environment before citing counts in new public claims.
- [ ] Check commit diffs and links.
