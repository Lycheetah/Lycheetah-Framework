## Reproduce

From this directory, with Python 3.10+, `pytest` and `cryptography` installed:

```sh
python3 verify.py
```

The integration runner copies the preserved tree to a temporary directory and
expects six suites of 28, 76, 14, 28, 30 and 31 test executions: 207 total.
Counts include repeated historical coverage, not independent experiments.
Forge VII launches temporary localhost providers and child processes; an
environment forbidding socket binding cannot complete it. No external service,
model, customer data or paid API is used. Original scenario runners may
overwrite their result files; run them in a copy.

Original handoff notes under `intake/` retain their pre-publication wording and
suggested paths. This README and the dated review describe the integration.
Individual supplied licences remain, including Apache notices in Forges V–VII.
