
Python >=3.10 standard library only. `lab.py` launches separate localhost provider processes and controller subprocesses; the experiment is synthetic and writes only temporary SQLite files and test results. Expect up to about one minute for the scenario matrix on some machines.

## Most important scientific distinction

**A valid permission is not evidence that an action was safe; a provider receipt is not independent proof that its claim is true; a successful local compensation is not proof that all external consequences were erased.**

Evidence should be read at its appropriate level:

- proposed action → controller record
- remote action → provider receipt (trusted provider required)
- external consequence → independent attestation if available
- human sovereignty → actual tested freedom to refuse, migrate, resume and understand

Do not turn the seven experimental forges into a claim of validated metaphysical free will or consciousness.
