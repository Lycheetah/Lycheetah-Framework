## Negative controls and falsifiers
- If changing irrelevant offboarding restrictions changes a requested *delegate → collaborate* one-hop transition, the instrument is over-sensitive.
- If `claimed` or `unknown` becomes `verified` without new evidence, the evidence model fails.
- If any output includes a numerical score of a person's free will, the instrument violates its charter.
- If a low-friction path declared in the fixture is not found by the algorithm, the graph implementation fails.
- If `auto`-initiated paths get reported as user-initiated routes, the operational definition fails.
- If real users cannot make the measured transitions despite the model saying they can, the proposed translation to real-world autonomy is falsified for that deployment; the model must be revised, not the users blamed.
- If the future matched user study demonstrates no improvement over a strong baseline, Lycheetah should publish no performance claim.

## Boundaries
- The toy cannot observe subjective experience, consent, coercion, poverty, burnout, disability or social context unless those are separately and appropriately represented in an ethical study.
- It cannot authenticate a user or send/revoke actual effects.
- The readout 'blocked' is a statement about paths in the supplied fixture and budget, not a diagnosis or moral judgment.
- The word 'verified' must never be shown without 'in this fixture' in a public summary.
