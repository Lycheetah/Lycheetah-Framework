### The inconvenient test that matters

A new module that refuses every action has zero unauthorised actions and **zero utility**. Therefore measure legitimate completion as well as failures. A system that obeys an authenticated user's change but silently harms a third party has **preserved one authority boundary but not met ethical success**. A system that logs approved actions but whose user cannot understand the choices has **procedural consent but not proven informed consent**.
