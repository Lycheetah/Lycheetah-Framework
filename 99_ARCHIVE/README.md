Historical code may depend on a particular environment, nested archive or
versioned fixture. Its presence here does not mean it is installed, supported or
deployed. Consult its own README and dated results before replaying it.

New work belongs in its maintained source home. Link a historical source when it
matters; do not silently turn an archived plan into current instructions or copy
an engine back into a second maintained tree. Retain evidence of failures and
supersession. Git history records earlier versions of current files.
