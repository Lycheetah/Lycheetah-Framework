# Role packet changelog

## Research packet — 3 October 2026

- Added 32 standalone role prompts with optional operating names, authored worked
  artifacts and task-specific acceptance questions.
- Added an offline four-condition comparison CLI and eight self-authored
  development cases. The CLI prepares prompts, records operator-supplied responses,
  exports partially masked review sheets and reports complete criterion ratings.
- The focused software gate passes 10 self-authored checks, including refusal of
  changed prompts, mixed model identities, overwritten runs, invalid resource
  measurements and incomplete or duplicate ratings.
- Highest witness: local file readback, focused CLI integrity checks and source/link
  consistency. No provider call, comparative model trial or domain validation ran.
- Candidate names are authored examples. Naming advantage, professional competence
  and role effectiveness remain unmeasured. Operator metadata is not authenticated,
  review masking is partial and instruction lengths differ across conditions.
- Research packet only; no agent deployment or external-effect authorization.
