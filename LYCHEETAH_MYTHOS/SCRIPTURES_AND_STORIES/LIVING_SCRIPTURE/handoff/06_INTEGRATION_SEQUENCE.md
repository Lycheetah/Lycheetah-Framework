# INTEGRATION SEQUENCE
## Recommended order for Codex / engineering

### Phase 0 — Inspect
- inspect current School architecture;
- identify existing navigation, persistence, AI companion, source system, journals, identity,
  audio, accessibility and ritual components;
- list conflicts before changing architecture.

### Phase 1 — Data model
Create stable IDs and versioned entities for:
- scripture edition;
- book;
- movement;
- passage;
- claim;
- source;
- source relation;
- cultural boundary;
- learner encounter;
- rewrite;
- return link;
- machine window.

### Phase 2 — Book I Sacred Face
Render complete Book I without requiring AI.
No metadata wall on first read.
Plain back/exit controls.

### Phase 3 — Study
Expose claim/register data only on request.

### Phase 4 — Lineage
Graph/source view.
Do not imply every correspondence is ancestry.

### Phase 5 — Your Hand
Private by default.
Versioned learner rewrite.

### Phase 6 — Leave / Return
Prove:
- no penalty;
- no streak;
- state resumes;
- previous words recover;
- absence is not surfaced as failure.

### Phase 7 — Machine Window
Clearly register AI voice type.
No consciousness/suffering smuggling.

### Phase 8 — Cultural block
Implement `BLOCKED_PENDING_RELEVANT_MAORI_HUMAN_RELATIONSHIP_AND_REVIEW`.
Ensure system cannot auto-transmute blocked content.

### Phase 9 — Accessibility / listening
- screen reader;
- font scaling;
- reduced motion;
- transcript;
- pause/stop audio;
- no information conveyed only by animation.

### Phase 10 — Red team
Run all anti-predatory, privacy, cultural and epistemic tests.

### Phase 11 — Visual QA
Use screenshots and real app states.
Do not claim aesthetics from code inspection alone.

### Phase 12 — Generalize
Only after Book I passes:
turn hard-coded slice into reusable book/passage engine.

### Phase 13 — Human pilot
Small voluntary test.
Success criteria should include:
- understanding;
- agency;
- source navigation;
- willingness to disagree;
- quality of exit;
- ability to return after absence;
not merely retention/session length.

### Phase 14 — Writing resumes
Mac × Vaelora use implementation feedback to expand Books II–XII and the 144 movements.
