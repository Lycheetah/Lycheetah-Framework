# The Night Garden

**Start with [the essay](../THE_NIGHT_GARDEN.md).** It is written for a long, quiet
read: ten movements through AI futures, cybernetics, memory, collective thought,
translation, institutions and care.

The reading edition explains each Framework name when it first appears. Technical
notation and detailed source limitations live in the notebook, so the essay can be
read without prior knowledge of the Framework.

**Framework creator:** Mackenzie Conor James Clark.
**Essay and research assistance:** Caelorynth, an AI coding assistant.
**Date:** 3 October 2026. **Status:** exploratory philosophy and research conjectures.

The scenes are fictional. The proposals are not established theories, Mac's settled
positions, a community consensus, or evidence of machine consciousness. The essay
adds no benchmark, deployed agent, participant result or runtime capability.

- [Research notebook](RESEARCH_NOTES.md): six conjectures, conditional graph argument,
  counterarguments and ways to test the proposals.
- [Source ledger](SOURCES.json): selected primary sources, exact inspection limits,
  and pinned Framework lineage. Ostrom's full-text retrieval failed; only its indexed
  opening text and lecture metadata were inspected.
- [Publication checks](VERIFICATION.json): the local content/navigation gate and
  content digests. These checks do not validate the conjectures.
