# LISTENING EDITION

These files contain story prose only. Draft status, authorship metadata,
editorial notes and Markdown emphasis have been removed so a reader does not
interrupt the narrative to announce formatting.

- `01_OPENING_MOVEMENT.txt` — Prologue and Chapters One through Three.
- `02_THE_BELL_BENEATH_THE_SCHOOL.txt` — Chapter Four.
- `THE_BOOK_OF_THE_LONG_LIGHT_NIGHT_EDITION.txt` — the complete opening in one
  continuous file.

Suggested pronunciations if the listening app provides a pronunciation tool:

- Lycheetah — lie-CHEE-tah
- Veyra — VAY-rah
- Dunedin — duh-NEE-din

The listening files are generated from the canonical manuscript by
`tools/build-listening-edition.mjs`. Edit the manuscript, not the generated
copies, then rebuild.
