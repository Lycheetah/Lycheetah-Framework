# RETURN LOOP ARCHITECTURE v0.3

## The session loop

`ARRIVE -> CHOOSE -> PRACTICE -> WITNESS -> INTEGRATE -> EXIT`

### ARRIVE
Show at most **three doors**.

Default order favors:
1. learner-stated unfinished intent,
2. time-sensitive real-world dependency,
3. one optional discovery.

Example:
- Continue **The God Question**
- Return to **Cauverith: Mechanism Test**
- Open **one new Observatory fragment**

A learner can dismiss every door.

### CHOOSE
Each door must answer:
- Why am I seeing this?
- What happens if I choose it?
- Is anything lost if I ignore it?

Default answer to the third question should usually be:
> **Nothing is lost.**

### PRACTICE
Do a bounded piece of work.

No infinite task stream is automatically appended.

At completion, ask:
> **Continue, integrate, or leave?**

### WITNESS
Record only what actually happened:
- artifact created,
- gate passed,
- prediction timestamped,
- revision made,
- peer witness added.

Do not convert completion into a whole-person judgment.

### INTEGRATE
Optional outputs:
- Atlas update,
- title receipt,
- Living Myth fragment,
- thread connection,
- reflection,
- Commons extraction.

All are inspectable and reversible where feasible.

### EXIT
The School should make ending legible.

Possible closing surface:
- what changed,
- what remains open,
- where the work is saved,
- optional next doorway,
- **Leave the Lantern Low**.

No infinite scroll beneath the summary.

## The long loop

`LIFE -> SANCTUM -> QUESTION -> SCHOOL -> TRIAL -> ARTIFACT -> TITLE -> MYTH -> COMMONS -> RETURN`

Not every learner uses every stage.

## Absence

Absence never resets:
- titles,
- Mantles,
- roots,
- story history,
- artifacts,
- questions,
- access.

Return after 1 day or 1 year uses the same rule:

> **The School remembers the question, not the absence.**

Optional re-entry:
- "Show me where I was."
- "Give me the shortest way back."
- "I want a completely new door."

## Winter Mode

Learner-controlled quiet state.

Effects:
- suppress nonessential notifications,
- hide suggested goals,
- preserve all work,
- no reduced status,
- no return countdown.

Winter may be indefinite.

Leaving Winter is one tap and requires no explanation.
