## Status
**PROPOSED / PROVISIONAL CANON.**

This is a complete v0.1 architecture, not a claim that every sound is globally unique or legally available.

Before public release, run deeper:
- trademark screening,
- multilingual offensive/collision screening,
- cultural consultation where relevant,
- live pronunciation tests,
- real learner testing for cringe/identity fit.
