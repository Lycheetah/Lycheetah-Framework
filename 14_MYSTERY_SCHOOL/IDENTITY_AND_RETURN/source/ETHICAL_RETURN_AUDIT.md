# ETHICAL RETURN AUDIT

Run this audit on every new engagement or progression feature.

## A. Autonomy
- Can the learner say no?
- Is refusal equally easy to understand?
- Is anything silently lost?
- Is personalization explainable?
- Can the learner alter or disable it?

## B. Competence
- Does the reward correspond to a real capability or bounded act?
- Is difficulty understandable?
- Can failure produce information instead of shame?
- Does the system distinguish practice from mastery?

## C. Relatedness
- Does social connection support inquiry?
- Can the learner participate without public status competition?
- Does absence create social guilt?
- Are peer witnesses scoped and consensual?

## D. Temporal integrity
- Does the feature exploit countdowns or appointment mechanics?
- Is urgency externally real or platform-manufactured?
- Does missing a time window erase value?

## E. Identity integrity
- Does the feature encourage a learner to over-identify with a title?
- Can the title be retired?
- Can the learner inspect why it exists?
- Does the system infer sacred identity without permission?

## F. Exit integrity
- Is there a clean stopping point?
- Can state be exported?
- Can notifications be quieted?
- Can the learner leave and later recover context?

## Decision
Any **NO** on autonomy, temporal integrity, identity integrity or exit integrity blocks release until resolved or explicitly governed.
