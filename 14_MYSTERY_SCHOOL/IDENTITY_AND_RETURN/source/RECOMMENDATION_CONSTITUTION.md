# RECOMMENDATION CONSTITUTION v0.3

The recommender is not an engagement engine.

## Permitted objective features

Recommendations may use:
- explicit learner goal,
- unfinished learner-owned work,
- prerequisite relevance,
- new evidence on a saved claim,
- chosen Mantle/Form,
- learner-requested challenge level,
- spaced review if enabled,
- peer response requiring attention,
- declared availability/time budget,
- learner-selected discovery domains.

## Prohibited optimization targets

Do not directly optimize:
- session duration,
- raw return frequency,
- number of clicks,
- notification opens,
- emotional arousal,
- outrage,
- fear of missing out,
- purchase conversion through learning friction.

## Every recommendation exposes

**WHY THIS?**

Example:
> You saved this question three weeks ago and CASCADE now has a tool that directly addresses the unresolved dependency.

**SKIP EFFECT**

Example:
> Nothing changes if you skip this.

**SOURCE OF URGENCY**

Example:
> No urgency.

or:
> Your learner-set exam is 5 days away.

## Diversity

Do not repeatedly recommend only the learner's strongest existing identity.

A Radvyr should sometimes be offered:
- rest,
- creation,
- relationship,
- uncertainty,
- a contrasting Mantle.

Personalization should widen available routes, not close the person around a profile.
