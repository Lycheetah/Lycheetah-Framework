# THE SIX LANTERNS OF RETURN

The return loop has six sources of pull. None is allowed to become coercive.

## 1. CURIOSITY — "Something remains unresolved."
The learner returns because a real question still has shape.

Surface:
- unfinished questions,
- Veiled Events,
- unresolved contradictions,
- new evidence attached to a saved question.

Never:
- fake cliffhangers,
- withholding available answers only to force return.

## 2. CONTINUITY — "My work still exists."
The learner returns because the system preserved context without punishing absence.

Surface:
- exact last state,
- waiting threads,
- Living Myth continuity,
- portable artifacts,
- saved experiments.

Return message:
> **Your work is where you left it.**

Never:
- "You missed 6 days."
- degraded rewards after absence.

## 3. CAPABILITY — "I can do something now that I could not do before."
The learner returns because real competence is becoming visible.

Surface:
- completed gates,
- reusable methods,
- before/after artifacts,
- witnessed trials,
- capability receipts.

Never:
- fake competence from accumulated points.

## 4. IDENTITY — "I am practicing a way of becoming."
The learner returns because a Mantle or Form gives a chosen practice emotional shape.

Surface:
- Mantles,
- Forms,
- earned epithets,
- Transmutation,
- retired titles,
- title receipts.

Never:
- identity lock-in,
- rarity prestige,
- algorithmically assigned personality.

## 5. BELONGING — "There are other minds here."
The learner returns because dialogue, witnessing and shared inquiry matter.

Surface:
- peer responses,
- collaborative trials,
- Commons discussions,
- voluntary witnessing.

Never:
- follower counts as status,
- social punishment for absence,
- public rankings,
- engagement bait.

## 6. CONTRIBUTION — "Something I learned can leave my private world."
The learner returns because private inquiry can become public usefulness.

Surface:
- methods,
- corrections,
- teaching fragments,
- source maps,
- experiments,
- Commons proposals.

Never:
- exposing private Sanctum material by default,
- rewarding quantity over utility.

## Balance rule

A healthy return loop should usually draw from at least two Lanterns over time.

If one Lantern dominates:
- Curiosity alone can become compulsive uncertainty.
- Continuity alone can become nostalgia.
- Capability alone can become achievement grinding.
- Identity alone can become role captivity.
- Belonging alone can become social dependency.
- Contribution alone can become productivity pressure.

The system should diversify opportunity, not intensify whichever motive produces the longest session.
