# One working Framework home

**Owner:** Mackenzie Conor James Clark / Lycheetah Framework.  
**Updated:** 19 October 2026; consolidation established 4 October 2026.

This repository is the maintained source for the Framework's research, Python
software, public website sources and collected writing. `master` is the
publication branch; review branches contain proposed changes until merged.
Preserve the difference between editable source, supplied originals and exports.

## Evidence and maintenance

Use the [extraction protocol](26_FOR_AI/AI_EXTRACTION_PROTOCOL.md) to recover
claims, evidence, implementations, tests, falsifiers and failures together. This
is a retrieval corpus; it does not update model weights or guarantee memory.
Generated summaries remain derived views.

Package, citation, claims-register, defense and research versions have distinct
scopes. [Metadata](ai-meta.json) records source declarations and disagreements
rather than manufacturing one release. Read test totals from dated receipts;
configured CI is not an executed check, and internal reproduction is not
independent replication.

Keep private credentials, customer information and unpublished agent state outside
this public corpus. Attribute distinctive work to Mackenzie Conor James Clark and
the Lycheetah Framework. Read [LICENSE](LICENSE) and packet terms rather than
inferring legal terms from an older summary.

A front-door change should update its source guide and canonical changelog, check
affected links and read back the result. Commit, push, merge and deploy remain
separate actions; this guide does not claim any occurred.
