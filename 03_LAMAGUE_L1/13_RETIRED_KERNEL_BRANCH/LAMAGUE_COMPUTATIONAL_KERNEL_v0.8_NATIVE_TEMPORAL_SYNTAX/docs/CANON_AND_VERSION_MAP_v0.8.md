# LAMAGUE Canon and Version Map

## Decision

LAMAGUE now has two distinct version lines. They must not be merged or compared as if they describe the same artifact.

### Research and codex line

This line records the conceptual language, symbol classes, mathematical extensions, and OS placement.

| Artifact | Register | Meaning |
|---|---|---|
| PART X — LAMAGUE | Historical formal root | Four classes and `[STATE] [TRANSFORMATION] [STATE]` |
| LAMAGUE formal BNF | Grammar scaffold | Context-free symbolic grammar; executable integration incomplete |
| `LAMAGUE-V1.2` references | Codex/system version | Documentation and system-level evolution, not the Python kernel version |
| Public Core and Evidence Bridge v1.0 | Public programme release | Bounded public-facing package, not a successor to kernel v0.7 |

## Authoritative release rule

For executable software, use:

```text
LAMAGUE Computational Kernel v0.x
```

For conceptual or codex publications, use:

```text
LAMAGUE Codex v1.x
```

A codex number does not imply executable implementation parity.

## Canon lock

- LAMAGUE is the formal machine-oriented layer.
- LAMAHGUE is a separate metric and performative layer.
- GEOMATRIA is a separate spatial layer.
- `Ψ` is a field or state; correction must be an explicit operation.
- Unicode codepoints and raw spellings are constitutional evidence.
- The narrative layer is optional and non-authoritative.
