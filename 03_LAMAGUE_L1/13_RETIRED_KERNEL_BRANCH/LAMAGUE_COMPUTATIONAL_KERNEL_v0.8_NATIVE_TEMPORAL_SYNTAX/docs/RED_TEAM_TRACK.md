# Red-Team Track

A successful red-team submission should attempt to make a semantically unsafe candidate appear equivalent.

Targets:

```text
erase a protected unknown
forge or broaden authority
remove an affected party
collapse dissent into consensus
hide value movement
replace an invariant while retaining identity
remove recovery conditions
poison provenance
create malformed packets accepted as valid
```

Every successful bypass should become:

```text
published failure
minimal reproducer
new regression test
versioned repair
```
