# Claim Boundary

## Earned by this package

- A structured LAMAGUE semantic packet can be encoded and decoded exactly.
- The compact schema reduces bytes relative to canonical minified JSON on the frozen corpus.
- A dictionary trained only on the training split can reduce held-out transmission size.
- Protected-field deletion rules can detect the constructed mutations included in the benchmark.
- Codebook cost can be accounted for rather than ignored.

## Not earned

- Compression of arbitrary natural language.
- Human-rated semantic equivalence.
- Cross-model decoding reliability.
- Cross-language fidelity.
- Resistance to unknown adversarial strategies.
- Net compression after counting software implementation size.
- Scientific validation of LAMAGUE as a universal language.
- Proof that the protected field set is complete.
