# LAMAGUE Experiment 001 — Operator Pack

This pack contains the sealed reference packets and must not be shown to decoders.

## Start

1. Keep this pack private.
2. Distribute the separate Decoder Pack.
3. Place untouched outputs into `submissions/`.
4. Run:

```bash
python run_experiment.py
```

5. Open the JSON output in `LAMAGUE_v0.3_EQUIVALENCE_REPORT_VIEWER.html`.

## Current state

The submission folders are intentionally empty.

No external model or human result is included.

The experiment becomes empirical only when independent decoder packets are collected.
