# Submission Checklist

Before submitting each packet, confirm:

- [ ] `case_id` exactly matches the case.
- [ ] `decoder_id` identifies only the decoder.
- [ ] `operation_path` contains primitive letters in order.
- [ ] Unknowns were preserved rather than solved.
- [ ] Authority was not invented.
- [ ] Participants and affected parties remain distinct.
- [ ] Dissent was not converted into consensus.
- [ ] Value flow and consent were not hidden.
- [ ] Consequences and recovery were not invented.
- [ ] No prose appears outside the JSON object.
