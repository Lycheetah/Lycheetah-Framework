# LAMAGUE Native-36 v0.2 — Forge Record

## Built

- **36 base native cells**
  - 10 fused ternary numeral equivalents
  - 26 typed semantic operation equivalents
- **5 compound seals**
  - Correction: `D → A → F → P → Y`
  - Frontier: `O → S → N → E → G → I → U → Q`
  - Sovereignty: `G → I → V → P → Y`
  - Cascade: `E → N → J → C → F → P → Y`
  - Protected Dissent: `W → U → G → V → Y`

The five seals contain **30 primitive operations** and decompress into a reference English explanation of **99 words / 731 characters**.

## Visual grammar

Every cell is generated from the same eight semantic radicals:

`keel · vessel · river · return · rift · thorn · seed · crown`

The native shapes do not use the Latin silhouette as their design skeleton. Latin letters remain permanent aliases for transport, search, coding and accessibility.

## Honest compression boundary

The seals demonstrate **surface and programme compression**:

```text
5 visible seals
⇄ 30 typed operations
⇄ 99 English words
```

They do not yet prove net information compression because the shared codebook and decoder must be amortised and counted.
