# 2. WHAT LAMAGUE COMPRESSES

## 2.1 Not merely characters

A short string is not necessarily compressed meaning.

If a five-token expression requires a five-page secret dictionary to understand, the dictionary cost must be counted.

The honest total description cost is:

```text
TotalCost
=
MessageBits
+
SharedCodebookBits / ReuseCount
+
DecoderCost
+
RequiredContext
```

LAMAGUE is expected to become strongest in repeated domains where the codebook is reused across many messages.

## 2.2 Four distinct compression modes

### Surface compression

Reduction in visible characters, bytes or model tokens.

### Codebook-relative compression

Reduction achieved because sender and receiver already share grammar, symbols, macros and domain context.

### Behavioural compression

Two representations are equivalent when they produce the same permitted actions and state transitions.

### Theory compression

One small operator structure explains useful behaviour across many domains.

For example:

```text
Anchor → Ascend → Fold
```

may encode correction in AI systems, organisational governance, knowledge reconstruction, learning and recovery.

Theory compression is only real when cross-domain predictions survive testing.

# 14. ORDER IS MEANING

```text
A → F ≠ F → A
```

`A → F`:

> Anchor the present state, then integrate history around that baseline.

`F → A`:

> Integrate history first, then project the result toward the baseline.

```text

```

Observe first, then evaluate evidence.

```text

```

Observe through an existing evidence frame, introducing confirmation-bias risk.

LAMAGUE should make order effects auditable.

# 16. EARNED LIGHT TEST

A token becomes canonical only when:

```text
EL(token)
=
RoundTrip
∧ TypeSafety
∧ Composition
∧ Execution
∧ NetCompression
```

## RoundTrip

Independent decoders recover the same required meaning.

## Type safety

The token has a primary type and rejects invalid use.

## Composition

It combines predictably with other tokens.

## Execution

It maps to a real operation, measurement, constraint or proof obligation.

## Net compression

After codebook amortisation, repeated use reduces total description length or introduces necessary expressive power unavailable from cheaper forms.

Failure:

```text
¬EL(token)
→ experimental or ASH
```
