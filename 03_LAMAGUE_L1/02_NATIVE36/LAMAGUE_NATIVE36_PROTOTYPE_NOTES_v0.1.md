# LAMAGUE Native-36 Prototype v0.1

## Files

- `LAMAGUE_NATIVE36_INTERACTIVE_PROTOTYPE_v0.1.html` — self-contained interactive transcoder and glyph explorer.
- `LAMAGUE_NATIVE36_GLYPH_SHEET_v0.1.svg` — scalable vector sheet.
- `LAMAGUE_NATIVE36_GLYPH_SHEET_v0.1.png` — mobile preview.
- `LAMAGUE_NATIVE36_REGISTRY_v0.1.json` — semantic IDs, aliases, private-use mappings and vector commands.

## What was built

Thirty-six single-cell glyphs:

- 10 fused native numerals, based on the existing LAMAGUE trinary lineage.
- 26 semantic operation glyphs corresponding to the current A–Z working map.

The marks are generated from a small semantic radical system:

`keel · vessel · river · return · rift · thorn · seed · crown`

ASCII remains a permanent debug and transport alias. The native glyphs are the experimental visual embodiment.

## Research boundary

This is an independently generated prototype, not a claim that every outline is globally unprecedented. A proper originality claim requires a visual similarity audit against historical, constructed and technical scripts.

The `U+E100...` identifiers are experimental Private Use Area agreements only. They are not official Unicode assignments.

## Distinguishability audit

- Mean pairwise raster separation: **0.859**
- Closest pair: **5 / 8 = 0.225**

These machine distances are only preliminary. Human recognition and confusion matrices are still required.
