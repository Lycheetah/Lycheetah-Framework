# LAMAGUE Canon Map

## Authoritative sequence

```text
v0.1 → v0.2 → v0.3 → v0.4
```

### v0.1

Established the first independent LAMAGUE core:

- primitives;
- operators;
- parser;
- runtime;
- canonical normal form;
- equivalence;
- semantic hashes;
- lossless macros.

### v0.2

Locked ontology and types:

- `Φ↑ = modify(Φ, ↑)`;
- `Ψ_inv = qualify(Ψ, inv)`;
- `∅` is intentional null, not missing information;
- explicit type hierarchy;
- typed operator signatures.

### v0.3

Locked transformation contracts:

- proven laws;
- refuted laws;
- undeclared laws;
- domain-dependent behavior;
- rewrite traces;
- no invented identity or annihilator;
- recurrence termination remains domain-dependent.

## Non-authoritative integration branch

The v0.7 and v0.8 computational-kernel releases remain preserved as research history.

They are not deleted or disowned. Their architectural role is:

```text
proof that LAMAGUE can host temporal evidence structures
```

Their correction is:

```text
those structures belong in adapters, not the core language
```

## Canon rule

No future adapter may:

- redefine a core primitive;
- change a core operator law;
- alias missing data to `∅`;
- silently reinterpret a glyph;
- promote domain claims into core truth;
- remove the original source representation.
