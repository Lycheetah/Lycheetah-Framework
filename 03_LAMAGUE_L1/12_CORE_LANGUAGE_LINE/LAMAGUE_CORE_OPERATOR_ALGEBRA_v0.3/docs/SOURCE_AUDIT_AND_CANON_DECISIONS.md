# Source Audit and Canon Decisions

## Preserved source identity

The early language defines LAMAGUE as a mathematical micro-language, symbolic
compression layer, semantic geometry, and bridge between conceptual and machine
structure. It establishes the pattern:

```text
[STATE] [TRANSFORMATION] [STATE]
```

The later formal grammar establishes four symbol classes and a context-free scaffold.
The first corpus expands this into seven classes, an 8-dimensional semantic vector
space, spoken forms, numerical encodings, algorithms, and domain extensions.

v0.1 does not pretend all these layers were already one consistent executable language.
It extracts the smallest defensible core.

## Contradiction ledger

### Ψ

Source meanings include drift field, fold operator, consciousness, awareness state, and
contextual variable.

**Decision:** core meaning is `generic fold/drift field`; adapters declare context.

### ↯

Source meanings include collapse, collision, entropy spike, and decision junction.

**Decision:** core meaning is directed collapse. Junction is excluded until assigned a
unique symbol.

### ∮

Source meanings include recursion and mathematical integration.

**Decision:** reserved for integration extension; recursion uses `⟲`.

### Ao versus A₀

Both appear as anchor notation.

**Decision:** canonical spelling is `Ao`; `A₀` is a warning-bearing alias.

### ∞ versus ♾

Both appear as closed infinite.

**Decision:** canonical spelling is `∞`; `♾` is a warning-bearing alias.

### Operators as atoms

The BNF lists `→`, `⊗`, `⇌`, and `⟲` as both operators and dynamic atoms.

**Decision:** they are operators only.

### Compression

The corpus contains ratios ranging from roughly 11:1 measured on small examples to
hundreds or thousands to one as broad assertions.

**Decision:** core reports local measured counts only. Broader ratios remain historical
claims pending reproducible corpora.

### Algebraic claims

The corpus states fusion is associative and commutative and that order matters for
Ascent and Fold.

**Decision:** fusion associativity and commutativity are canonical. Idempotence is not
assumed. Directed transformations remain noncommutative.
