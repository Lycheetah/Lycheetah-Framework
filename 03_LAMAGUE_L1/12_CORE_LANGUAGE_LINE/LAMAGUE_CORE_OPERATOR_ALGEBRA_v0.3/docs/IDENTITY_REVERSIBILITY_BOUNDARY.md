# Identity and Reversibility Boundary

## Identity

No universal identity element is currently declared for any operator.

The invariant marker `⟟` is not automatically an identity.

The null state `∅` is not automatically an identity.

## Annihilation

`∅` is not a universal annihilator.

```text
A ↯ ∅
```

is a collapse relation whose target is intentional null. The entire expression is not
rewritten to `∅`.

## Structural inverse

A structural inverse concerns normalized symbolic equivalence.

Exchange is self-inverse in this narrow sense:

```text
A ⇌ B ≡ B ⇌ A
```

## Operational reversibility

Operational reversibility concerns whether an external state change can be undone.

The core has no domain state engine, so operational reversibility is domain-dependent for
all six operators.
