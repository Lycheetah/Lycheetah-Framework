# LAMAGUE Runtime v0.2 — Semantic Continuity Engine

Runtime v0.2 extends the bounded v0.1 prototype with five continuity mechanisms:

1. **Semantic identity hashing** — canonical meaning receives a stable SHA-256 identity independent of random node or programme IDs.
2. **Breathing compression** — `Z↓` compresses only under low-risk, shared-context, high-decoder-confidence conditions; `Z↑` expansion is forced when meaning or agency is endangered.
3. **Protected dissent** — unresolved positions remain attributable and cannot be silently erased by a merge.
4. **Visible value ledger** — hidden or unconsented extraction triggers isolation.
5. **Lineage-preserving memory and migration** — state changes are classified as `CONTINUATION`, `DESCENDANT`, `FORK`, or `IMPOSTOR`.

## Scope

This runtime operates only over abstract in-memory state. It does not control external systems or claim general natural-language understanding.

A compact semantic object is useful only if its protected meaning, unknowns, dissent, value flow, and lineage survive decompression, execution, and migration.
